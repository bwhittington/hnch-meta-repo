# Prompts

Reusable prompt snippets for HNCH estimation work.

## Conventions

- One concern per file; prefer short, composable prompts over monoliths.
- Reference `docs/estimation-model-overview.md` instead of restating the full model.
- Never embed secrets, API keys, customer rates, or proprietary client data.
