# Context

Scratch and source notes that help agents understand the estimation model without putting secrets in git.

## What belongs here

- Pointers to the Excel workbook location (Project store, local path, symlink).
- Derived notes, sheet maps, and open questions about the model.
- Non-sensitive excerpts or screenshots that clarify behavior.

## What does **not** belong here

- API keys, tokens, passwords
- Customer-specific bill rates or proprietary pricing dumps you do not want in git
- Full app source (that lives in `hnch`)
