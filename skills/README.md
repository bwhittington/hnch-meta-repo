# HNCH Agent Skills

Canonical skills live here as Agent Skills packages:

```
skills/<name>/SKILL.md
```

Cursor project auto-load uses the mirror:

```
.cursor/skills/<name>/SKILL.md
```

Keep both in sync when editing. These are **real** `SKILL.md` skills (YAML frontmatter + body), distinct from the separately installed [skyfox675/agents-skills](https://github.com/skyfox675/agents-skills) harness.
